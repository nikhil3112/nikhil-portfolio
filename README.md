- Selected SaaS, AI automation, OCR, HRMS, Payroll, and LMS case studies

## Stack

- React
- Tailwind CSS
- Framer Motion

## Local development

```bash
npm install
npm run dev
```

For Create React App projects, use:

```bash
npm start
```

## Content updates

Edit `src/portfolioData.js` to change profile information, experience, projects, skills, education, and contact links without editing the page layout.

Place the current resume at:

```text
public/Nikhil_Anande_Resume_September_2026.pdf
```

## Deployment

Build the project using the command configured in `package.json`, then deploy through the repository's existing GitHub Pages workflow.

Before publishing project screenshots, repositories, live demos, client names, or architecture details, confirm that the material is approved for public use.
